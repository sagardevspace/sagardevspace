### MargDarshak — AI-Powered Career Guidance & Skill-Gap Analysis

A web-based career guidance platform that helps students understand how their existing skills align with the requirements of their target job roles.

**Key Features:**
- Resume text extraction
- Keyword-based skill extraction
- Job requirement comparison
- Skill-gap identification
- Learning recommendations (proposed enhancement)
- Job and internship recommendations (proposed enhancement)

**Implemented baseline:**
- Resume text extraction
- Keyword-based skill extraction
- Baseline skill matching
- Baseline skill-gap identification

**Future Enhancements:**
- NLP-based semantic matching
- Embeddings and cosine similarity
- Advanced recommendation models
- Personalized learning roadmaps
- Career dashboard and assistant

**Planned Tech Stack:**
React.js | JavaScript / TypeScript | Node.js | Express.js | Firebase Firestore | Firebase Authentication | Firebase Storage
